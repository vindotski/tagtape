# TagTape
> Convert YouTube to MP3 with metadata for standard MP3 players.

TagTape addresses the problem most YouTube to MP3 converters face and that's not providing options to automatically edit metadata. Even better, TagTape allows you to fill in metadata for multiple tracks.

[Try out TagTape!](https://tagtape.app)
